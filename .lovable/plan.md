# خطة إعادة تصميم Dashboard التحليلي

## النطاق
- تعديل واجهة `dashboard.tsx` ومكونات العرض الحالية في `sections.tsx` فقط عند الحاجة
- إبقاء مصادر البيانات والمنطق والتحليل والـAI والربط كما هي تمامًا
- عدم إضافة مكتبات أو بيانات تجريبية أو تغييرات خلفية

## التنفيذ
1. إعادة بناء أعلى الصفحة كلوحة KPI واضحة تجمع درجة HOOK وأهم مؤشرات الحساب بأرقام لاتينية
2. تحويل بيانات الجمهور الفعلية إلى رسوم وقوائم مرتبة عبر Recharts مع حالات `—` للقيم غير المتاحة
3. تنظيم أداء الفيديو وصحة المحتوى في مؤشرات ورسوم مختصرة، مع الإبقاء على أفضل وأسوأ الفيديوهات الحالية
4. عرض نقاط الضعف والفرص من النتائج الحالية، ثم التوصيات حسب الأولوية دون تغيير محتواها
5. تحويل الخطة الأسبوعية إلى مخطط زمني متجاوب يعرض النوع والهوك والدعوة والهدف
6. إزالة التكرار البصري فقط مع بقاء جميع البيانات الحالية قابلة للوصول ضمن تبويبات الداشبورد

## التحقق
- فحص العرض على الجوال والديسكتوب
- تشغيل typecheck وbuild فقط
- عدم النشر
